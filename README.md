# JH Eisenach – Google review signature

Hosts the images for the Google review card used in the Gmail signature of the
Jugendherberge Eisenach. The card links to the hostel's Google review page.

| File | Purpose |
| --- | --- |
| `jh-eisenach-review-widget.html` | The signature card. Open it in Chrome, press Ctrl+A, Ctrl+C and paste it into Gmail's signature editor. |
| `jh-eisenach-logo.png` | Hostel logo on a white rounded tile (shown at 172×127 px, stored at 2×). |
| `google-g.png` | Google "G" badge (shown at 30×30 px, stored at 3×). |

The images are served with GitHub Pages:

- https://sumrizeventure.github.io/jh-eisenach-signature/jh-eisenach-logo.png
- https://sumrizeventure.github.io/jh-eisenach-signature/google-g.png

**Keep this repository public and keep the file names.** Emails that have already
been sent load the images from these addresses. To swap an image, upload a
replacement with the same name and size.
